# 期刊阅读列表

主站 `EditorialBrowse` 的阅读列表让纯文本正文与收藏按钮共用首行，正文使用可伸缩轨道，收藏控件保留独立点击与键盘焦点。来源、时间、独立标题和作者位于后续行。`editorial-list.css` 只匹配主站 `layout-list` 的 `post-card--text`；主站首页共用卡片的文字呈现计算。

正文最多呈现六行，DOM 和模型仍保留全文。打开正文入口进入现有详情；收藏按钮继续发出原帖对象和点击事件。图文卡片仍保留图片、主标题和具有额外信息的摘要。

## 标题与当前正文的来源

`JournalPost` 的两个可选字段用于呈现判断：

- `titleOrigin` 记录 API 标题为 `unknown`，或现有模型兜底生成的 `fallback`。
- `textOrigin` 记录当前正文来自 `post`、`favorite-note`，或无法确认的 `unknown`。

模型保留原来的标题、正文和收藏笔记真值选择。收藏详情可以继承原帖标题，再用个人笔记或详情 description 替换显示正文；两个来源分别记录。旧引用没有这些字段时仍可使用，卡片保留不同的标题。

`post-copy.ts` 仅返回标题和图片摘要的可见性，空白归一化只用于比较。作者文本、空行、大小写、标点、图片 alt 和详情标题沿用原值。

| 情境                                       | 卡片行为                                                                                  |
| ------------------------------------------ | ----------------------------------------------------------------------------------------- |
| 标题与正文在归一空白后相同                 | 呈现一次正文；图片卡片仍保留主标题                                                        |
| 原帖正文与本地兜底完整标题前缀相同         | 纯文本卡片省去第二份兜底标题                                                              |
| 个人笔记、不同 description 或来源未知      | 保留不同的原帖标题和当前正文                                                              |
| 短标题、大小写或标点不同                   | 保留独立标题                                                                              |
| 未知标题为长省略号摘要，且当前正文来自原帖 | 前缀至少 80 个 Unicode 码点并逐字匹配、正文还剩至少 32 个码点时，纯文本卡片省去第二份标题 |
| 图片摘要有额外文字                         | 保留原始摘要                                                                              |

摘要判断使用 Unicode 码点计数，并在达到阈值后停止；不把 emoji 的 UTF-16 单元数当作字符数，也不为完整长正文创建字符数组。标题字段仍保留，供详情、搜索和无障碍名称使用。

## 验证

定向用例覆盖模型来源、原有兜底与收藏笔记、80/32 和 Unicode 边界、大小写/标点误判、完整多段正文、图片 alt、收藏事件与按钮状态。组件事件测试同时比较组件收到的响应式对象与其底层原对象。

```powershell
node scripts/run-vitest.mjs run src/features/journal/__tests__/models-copy.spec.ts src/features/journal/__tests__/post-copy.spec.ts src/features/journal/__tests__/JournalPostCard.spec.ts --maxWorkers=1
```

排版、主题、键盘、减少动效及收藏详情迟到仍由候选与正式浏览器矩阵验证；单测不代替这些界面检查。列表成本与首页 LCP 分别测量，局部交互改善不抵消首页回退。
