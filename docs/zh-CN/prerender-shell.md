# 初始浏览壳

公开文案、链接与结构化数据由 `src/edge/htmlDocument.ts` 决定，展示由 `src/edge/prerenderShell.ts` 生成。主站使用紧凑的刊物结构，Next 保留摘要、记录信息与公开图片。所有服务端文案与属性保持 HTML 转义，展示层不解析或重写路由元数据。

`src/bootstrap/prerender.css` 随现有 bootstrap 插件内联，独立于主应用的 CSS 与脚本。作用域仅限初始壳，字体、尺寸、颜色与间距明确设置，减少完整 CSS 后到引起的重排。页面接管后初始 DOM 被移除。

启动代码用临时 `data-bootstrap-color` 属性提供已保存明暗偏好，应用挂载后清理。禁用 JavaScript 时无法读取本地保存项，初始壳跟随系统配色并显示交互限制说明；公开链接仍是普通文档导航。加载文本只在启动脚本运行时出现，不在禁用脚本页面制造持续等待。

公开入口至少 44px，手机使用整行布局，键盘有明确焦点样式。初始壳不额外播放动画，正常应用仍遵循已有完整/减少动效选择。启动超过既定阈值或入口失败时，已有独立恢复页负责提示和主动重试。
