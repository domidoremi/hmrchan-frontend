# 页面语言与路由元数据

`src/utils/pageMeta.ts` 的 `applyPageMeta` 同时服务查询条件变化和跨页面导航。标题、描述、canonical、社交元数据与结构化数据每次按当前页面更新。

根节点语言只在目标语言与 `document.documentElement.lang` 不同时赋值。浏览器对相同值的属性赋值也会记录属性突变；本次浏览器探针观察到这类赋值引起全局语言样式失效。同语言查询切换保持当前根节点语言。

语言选择和初始化由 `src/i18n/index.ts` 负责。真实语言变化继续更新根节点。函数直接读取当前 DOM 的语言属性，初始化、恢复和其他调用路径对根节点的更新均参与比较。

## 初始化与字典

初始导航与异步语言字典加载并行，默认语言代码在加载前已使用保存值。`src/router/routePageMeta.ts` 同时观察当前语言代码和当前字典对象；字典加载或替换完成后，使用最新匹配路由重新同步元数据。同语言字典就绪也会更新标题、Open Graph 与 Twitter 标题。

监听保持默认 pre 调度，未匹配路由不写入元数据，非当前语言字典的更新不触发同步。应用加载、路由守卫与认证流程按原顺序执行。

## 回归检查

`src/utils/__tests__/pageMeta.spec.ts` 使用 MutationObserver 检查：

- 英语、简体中文、繁体中文、日语的同语言查询切换及跨页元数据更新不产生 `lang` 属性突变。
- 真正语言变化仍写入根节点，并更新当前和三个备用 Open Graph 语言。
- 标题、描述、canonical 与已有结构化数据规则继续生效。

`src/router/__tests__/routePageMeta.spec.ts` 使用真实 i18n、Vue 响应式路由和文档元数据检查同语言迟加载、等待期间导航、真实语言变化、未匹配路由、非当前字典更新及当前字典替换。

实际浏览器需要分别检查保存语言后的首次加载、查询切换、跨页导航和语言设置。初始化与会话中的语言切换是不同场景；没有执行的设置或硬件检查不能作为通过记录。
