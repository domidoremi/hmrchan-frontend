# 首页媒体优先级

主站空间封面中，当前记录的图片使用高请求优先级，其他封面使用低优先级。邻近纸张继续加载缩略图以保留堆叠效果；只有当前记录允许按实际显示尺寸与屏幕密度升级原图。切换选择后重新检查清晰度需求，已经取得的原图不因切到背景而降回缩略图。

`JournalImage` 的 `upgrade` 参数默认开启。设置为 false 仅推迟正常清晰度升级：缩略图损坏时仍尝试原图；原图也失败则显示可访问的替代说明。原图升级失败而缩略图有效时继续显示缩略图，不反复重试同一失败资源。src 或 originalSrc 变化后重置这组状态。

Next 的当前选中预览使用高优先级；索引行继续按现有尺寸使用缩略图。首页初始文档不再预加载固定的旧 fallback 封面，fallback 数据仍保留，实际使用时按普通图片请求加载。详情页的有效媒体预加载不受影响。

性能验收区分初始 HTML 的 LCP、动态正文、图片 load、浏览器 Element Timing 与可见动画帧采样。Element Timing 在某些透明度过渡下缺失时，不用 load 值填充绘制时间；真实网络测量与受控媒体故障回归分别留档。
