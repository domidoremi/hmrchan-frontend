# UI/UX 验收记录

2026-11-22 更新。本轮仅重构 Next 正式源码。最新要求是移除可见的 MomiChan / Next 品牌、减少说明，并同时进化四个主题的布局、照片呈现、动画和完整交互。下方两站的既有性能与发布结果保留为历史对照。

## 验收要求

1. 基于两个正式前端仓库继续完善，保留内容、功能和完整交互能力。
2. 主站面向成熟阅读体验，Next 以写真、成员和活动呈现偶像站的未来感与精致感；两站使用不同的页面组织方式，不使用拱形推荐封面。Next 的页面、浏览器标题、PWA 和通知不展示 MomiChan、NEXT、next 或 n↗ 品牌标识，首页不重复顶栏设置第二排目录。真实作者名称和原帖内容保持完整。
3. 保留可见、细致的转场、悬停、滚动和持续动效，动效质量至少达到正式版水平。
4. 连续滚轮可以自然经过首页内容和背景变化。
5. 区分区域内部浏览与越过区域；内部媒体区和预览区在首尾释放页面滚动，区域不会困住用户。
6. 保留纸页、玻璃、庭院、光谱四个主题，每个主题独立定制布局、字体、元素、状态和动效。
7. 明暗模式、大字号和所有交互状态在四主题中保持清晰可读。
8. 文案和架构保持简洁，动效选择放在设置中，同时满足 UX、DX、AX 和功能兼容要求。
9. 新访客和恢复显示默认使用完整动效；用户明确保存的跟随系统或减弱选择继续生效。
10. 页面以自然文档流连续推进，布局、排版、背景和动效保持整体关系，不把普通内容做成逐屏停驻舞台。

## 当前实现

### 两站定位

- 主站保留刊头、阅读跨栏、影像横卷、日程和讨论章节，文章标题、摘要、署名和展开阅读是第一层信息。
- Next 首屏以写真与现场照片为主体，显示真实作者、发布时间和原帖标题；标题直接打开阅读内容。动态使用自然图片高度和带署名、来源、时间与标题的照片卡片，以贪心排布填充列间空缺。搜索、筛选、排序、列表切换、键盘选中和预览继续可用，搜索时保留输入节点和焦点。桌面保留一套功能导航；手机使用底栏，更多入口补充作者、收藏、搜索、已记日程、显示设置和账号。
- 两站共享内容、设置、阅读弹窗和无障碍语义；主页的版式、导航形态、信息密度和动效节奏分别定制。

### 四套独立构图

- **纸页 `minimal-editorial`**：平直的写真双页，照片居左，衬线标题与照片控件在右侧相邻编排；细线分隔、纸边和方形控件形成印刷感。
- **玻璃 `fluent-soft`**：居中的柔光相册，照片、选择控件和标题上下编排，使用圆角相框、柔和底色、无衬线标题和缩放曝光转场。
- **庭院 `organic-natural`**：错落的写真手帖，标题、署名、操作和照片形成不对称关系，使用微倾斜相框、自然角部和较舒展的衬线字形。
- **光谱 `gradient-narrative`**：宽幅舞台画报，主副照片、真实帖子标题和底部照片选择组成完整画面；舞台柔光在内容后方缓慢移动。

主题差异同时覆盖作者卡、官方链接目录、搜索、认证、月历、讨论、阅读弹窗、设置和加载状态。纸页使用侧标题与紧凑横排，玻璃使用居中相册与三列目录，庭院使用不等宽列与错落相框，光谱使用宽幅照片与不同的主副区域比例。完整动效下的主题切换使用原生 View Transition，照片、标题和控件分别参与位置与尺寸转场；照片切换、入场、悬停、日历和阅读动画按主题定制。

主站的背景由 `HomeAtmosphere` 和 `ThemeSceneArtwork` 提供独立 SVG 空间。Next 的写真首屏使用独立的 CSS 柔光与纸面构图，移除轨道、透视网格、巨幅流线和仪表式背景。背景不读取文章图片、标题、摘要或检索结果生成路径、网格或几何形变；照片只用于内容展示。当前实现没有 canvas、WebGL 或 3D 背景场景。

页面滚动通过 CSS view timeline 或单个 RAF fallback 更新背景进度；滚动、章节位置和视口动效经过读写批处理。完整动效保留背景光照、章节入场、悬停和媒体反馈，减弱动效停止持续运动并回到自然文档流。窗口隐藏、弹窗打开、场景离开视口时暂停对应动画。

主站推荐媒体和影像横卷可以在区域中央接收滚轮；到达首尾、从边缘进入、触摸大幅移动或继续向外滚动时释放页面。Next 首屏保持自然文档流，照片区域不接管页面滚轮，仍可通过按钮、方向键和触摸横向切换。普通阅读、列表、日程和讨论保持自然页面滚动。短屏和大字号优先保证内容可达，不强行压缩文字或截断操作区。

## 验收字段

- 约束：测试固定覆盖四主题、两种色彩模式、两种字号、完整与减弱动效，以及 `1440x900`、`390x844`、`320x640` 三种视口；背景几何只来自独立场景图形，内容数据不参与路径、网格或形变；媒体区和预览区在首尾释放页面滚动。
- 默认值：新访客使用完整动效和标准字号；主站默认 `minimal-editorial` 纸页主题与亮色模式，Next 默认 `gradient-narrative` 光谱主题与暗色模式；已保存的主题、色彩、字号和动效设置优先恢复，包括用户明确选择的跟随系统设置。
- 输出：验收生成性能 JSON、浏览器交互结果、Vitest 结果、生产构建结果、安全/SRI 结果、bundle 预算结果和 Pages 发布核验结果；性能采样和浏览器诊断使用本轮临时目录，门禁诊断使用对应仓库的 `output/validation/`，本记录保留结果汇总。
- 失败行为：合同、格式、类型、lint、复杂度、测试、构建或性能验收失败时停止后续提交与推送，并保留失败日志和诊断产物；修复后从失败步骤重新执行。发布核验失败时保留部署诊断，交付状态保持未完成。

| -------------- | -----------: | -----------: | -----------: | -----------: | --------: | --------: |
| 主站 1440 完整 |       60.7ms |        9.4ms |          482 |            0 |        92 |         0 |
| 主站 390 完整  |       53.3ms |        7.7ms |          562 |            0 |        37 |         0 |
| 主站 320 完整  |       52.4ms |        7.2ms |          559 |            0 |        29 |         0 |

| Next 320 完整  |       60.8ms |       17.8ms |          432 |            3 |        54 |         3 |

完整动效全部场景的总体平均为：基线 RAF p95 `53.7ms`、`3219` 个超过 25ms 的帧、`229` 个 LoAF；当前 RAF p95 `10.2ms`、`5` 个超过 25ms 的帧、`3` 个 LoAF。减弱动效总体平均为：基线 `8.1ms` / `1` 个超过 25ms 的帧，当前 `8.0ms` / `0` 个超过 25ms 的帧，LoAF 均为 `0`。
