## 当前实现

### 两站定位

- 主站保留刊头、阅读跨栏、影像横卷、日程和讨论章节，文章标题、摘要、署名和展开阅读是第一层信息。
- Next 以真实照片、成员和活动为内容主体，保持前沿未来的整站视觉；搜索、筛选、键盘选中和预览是保留的内容访问能力。
- 两站共享内容、设置、阅读弹窗和无障碍语义；主页的版式、导航形态、信息密度和动效节奏分别定制。

### 四套独立构图

- **纸页 `minimal-editorial`**：硬朗版心、双线刊头、分栏规则和页边注记。导航使用平直的编号栏，阅读区强调正文列宽和纸面留白。
- **玻璃 `fluent-soft`**：透光流带、镜面边缘、中心透镜和悬浮控件。导航使用圆润的浮层，搜索和预览通过半透明层级区分信息。
- **庭院 `organic-natural`**：不对称自然边缘、植物线稿、斜向路径和错落分组。导航沿路径分布，卡片和标题使用有机角部，页面重心保持松弛。
- **光谱 `gradient-narrative`**：轨道、标尺、棱镜色带和资料工作台。导航采用带选中光带的方形索引，Next 的结果列表与预览形成仪器式双栏。

背景由 `HomeAtmosphere` 和 `ThemeSceneArtwork` 提供一层独立设计的 SVG 空间，并使用渐变、纹理、线条和光照构成。背景不读取文章图片、标题、摘要或检索结果生成路径、网格或几何形变；内容数据与背景几何保持独立。当前实现没有 canvas、WebGL、透视相机或 3D 场景。

页面滚动通过 CSS view timeline 或单个 RAF fallback 更新背景进度；滚动、章节位置和视口动效经过读写批处理。完整动效保留背景光照、章节入场、悬停和媒体反馈，减弱动效停止持续运动并回到自然文档流。窗口隐藏、弹窗打开、场景离开视口时暂停对应动画。

推荐媒体和影像横卷可以在区域中央接收滚轮；到达首尾、从边缘进入、触摸大幅移动或继续向外滚动时释放页面。普通阅读、索引、日程和讨论保持自然页面滚动。短屏和大字号优先保证内容可达，不强行压缩文字或截断操作区。
