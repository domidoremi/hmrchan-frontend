### 四套独立构图

- **纸页 `minimal-editorial`**：沿线上写真双页编排，照片居左，衬线原帖标题、正常字号的署名与换照控件在右侧相邻排布；平直页边、纸面分隔和短距离入场保持印刷感。
- **玻璃 `fluent-soft`**：居中的柔光相册，照片、标题和选择控件紧凑纵向编排，使用透光层级、镜面边缘、圆润控件、无衬线标题和缩放曝光转场。
- **庭院 `organic-natural`**：错落的写真手帖，标题、署名、操作和照片形成不对称关系，使用轻微倾斜相框、自然角部、舒展的衬线字形和斜向背景纹理。
- **光谱 `gradient-narrative`**：沿线上照片主区与相邻文字控件构图，宽幅主照和小尺寸现场照片位于上方，原帖标题、署名、时间和换照区在下方相邻编排。整站使用冷色明暗令牌、利落边缘、少量色谱光带、等宽辅助字形和方向明确的照片切换；不放大作者名，不使用被否定的左侧大署名构图。

主题差异同时覆盖导航、图集、列表预览、作者卡、官方链接目录、搜索、认证、月历、讨论、阅读弹窗、设置和加载状态。共享材质、选中色、边缘、控件形状和辅助字形令牌贯穿这些页面；既有不等宽列和各主题的页面组织继续保留。切换代码保留原生 View Transition，照片、标题和控件分别参与转场；真实原文转场及持续动效录像已补入“真实绘制续检”，仍待用户验收。

首屏沿线上照片主体与相邻文字、控件关系调整，作者保持署名层级，完整原帖标题继续直接打开阅读内容。照片切换同时更新标题、计数和当前缩略图进度，离场字幕不再进入键盘与无障碍访问序列。完整动效保留照片曝光、字幕切换、章节入场、滚动深度和背景光照；悬停、键盘焦点、用户暂停、弹窗、页面隐藏或首屏离开视口时暂停对应照片与柔光，减弱动效保留静态照片和手动选择。这些是当前实现项目，视觉表现仍待实测和用户验收。

主站的背景由 `HomeAtmosphere` 和 `ThemeSceneArtwork` 提供独立 SVG 空间。Next 的 `NextAtmosphere` 位于整站工作区的背景层，使用独立 CSS 光照与平面构图：纸页页边线、玻璃透光面、庭院斜向纹理和光谱冷色切面按主题切换。背景不读取文章图片、标题、摘要或检索结果生成路径、网格或几何形变；照片只用于内容展示。当前实现没有 canvas、WebGL 或 3D 背景场景。

页面滚动通过 CSS view timeline 或单个 RAF fallback 更新背景进度；滚动、章节位置和视口动效经过读写批处理。完整动效保留背景光照、章节入场、悬停和媒体反馈，减弱动效停止持续运动并回到自然文档流。窗口隐藏、弹窗打开、场景离开视口时暂停对应动画。

主站推荐媒体和影像横卷可以在区域中央接收滚轮；到达首尾、从边缘进入、触摸大幅移动或继续向外滚动时释放页面。Next 首屏保持自然文档流，照片区域不接管页面滚轮，仍可通过按钮、方向键和触摸横向切换。普通阅读、列表、日程和讨论保持自然页面滚动。短屏和大字号优先保证内容可达，不强行压缩文字或截断操作区。
