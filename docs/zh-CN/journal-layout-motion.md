# 浏览视图重排动效

主站的画廊、照片墙和阅读列表共用 `runtime/layout-motion.js`。Next 使用独立的资料列表，运行时代码保持同步。

`EditorialBrowse` 在布局属性实际变化时捕获旧位置，等待 Vue 更新 DOM 后，由运行时统一读取目标位置，再批量启动 transform 动画。不要恢复成在点击时等待固定帧数猜测路由更新，也不要在每张卡片读取位置后立即写动画。

每个容器只允许最新请求启动动画。新请求从当前可见位置接续并取消旧动画，减少动效直接更新内容。销毁、容器移除或偏好变化后，等待中的请求不能重新播放。无尺寸变化的卡片不需要重排动画。

验证入口：`runtime/__tests__/layout-motion.spec.js` 与 `__tests__/EditorialBrowse.spec.ts`。几何排序与生命周期由单测覆盖；真实中间帧、主题尺寸、焦点和性能需浏览器验收。此优化不在首页启动路径，不能据此宣称首页 LCP 或 TBT 改善。
