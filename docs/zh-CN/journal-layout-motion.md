# Journal 界面、布局与阅读动效

主站默认使用纸页主题、衬线刊头、阅读跨栏和矩形照片卡组。首页包含封面、动态、影像、日程和讨论。目录随页面滚动更新当前章节与阅读进度，滚到页底会选中最后一章。其他主题同时改变色板、构图、控件和运动；横向相册可以展开阅读。

Next 首页先显示搜索和资料索引。桌面左侧选记录、右侧看预览，手机将预览排在列表上方。图库与索引共用 `NextCollection`，切换时保留筛选条件，首页链接中的 `?view=grid` 可以直接打开图库。两站共用显示设置和动效运行时，各自的入口样式由 `styles/index.css` 选择。

Next 的立体推荐放在索引下方。`useCoverPlayback` 记录推荐区首次进入视口的时刻，照片、标题与轨道从那时开始入场。离开后再滚回来会保留当前画面。完整动效下，同时可见的行缩略图和预览图之间有 640ms 过渡。纯文字记录直接显示文字。连续选择、滚动、打开阅读和改为减弱动效都会撤掉旧图层并恢复实际图片。

推荐和相册使用完整内容集合，来源筛选只改变信息流。Next 提交关键词后收起推荐场景，清空关键词后恢复。图片浏览与资料索引切换保留关键词、来源和排序；资料索引密度只在显示设置中调整。

`JournalAppearanceDialog` 固定标题和底部操作，中间选项独立滚动。动效有完整、减弱、跟随系统三个选择，首次访问默认完整，首页没有常显的动效开关；保留已保存的明确选择。明暗模式和外观预设沿用设置仓库；`displayPreferences.ts` 保存字号与索引密度，并监听同源标签页的存储变化。恢复显示默认会重置明暗为跟随系统、预设为当前站点默认、动效为完整、字号与密度为标准，保留界面语言。

首页按连续文档组织：阅读、索引、日程和讨论保留自然高度，不添加停驻距离。完整动效且可用高度不少于 360px 时，仅推荐卡组与影像横卷使用 `ImmersiveChapter` 的固定视口，滚动距离直接推进媒体，首尾自然离开。`useChapterScene` 分开输出连续经过进度和媒体进度；Next 仅在预览能放入可用高度时使用原生 sticky。减弱动效和短屏取消固定及裁切。

`HomeAtmosphere` 独立计算全页进度，跨区域时不会归零。背景、刊头、照片、阅读卡片、月历和讨论随同一文档位置连续变化；卡片图片与文字共同移动，避免压住说明。构图和主题差异由 `home-composition.css`、`home-themes.css` 管理。移动索引操作栏仅在索引区域内显示，媒体区域可见时暂时收起浮动回顶按钮，避免遮挡控制与作者信息。

`useHomeScroll` 延迟加载已有 Lenis 依赖，平滑首页的竖向滚轮输入。触摸、修饰键、表单、弹窗及原生横向手势保持浏览器行为；目录和媒体控制跳转共用同一个滚动实例。弹窗或页面隐藏时停止惯性，减弱动效、短屏及组件卸载时销毁实例；加载失败仍可原生滚动。

`useCoverPlayback.ts` 在增强模式下将滚动映射为小数位置，照片逐帧推进，不等待整张切换动画；文字保留稳定占位，只显示当前一篇，Next 文案容器统一入场。手动控制滚动到对应位置，暂停冻结照片选择。非增强模式保留 6.5 秒自动播放：悬停、焦点、弹窗、隐藏页面、离开视口、减弱动效和手动暂停都会停止计时。触屏横向手势切换推荐，竖向手势保留页面滚动。`pagehide`、组件停用和卸载清理计时器，重新显示或激活后按当前环境恢复。

| 行为               | 时间   | 实现位置                         |
| ------------------ | ------ | -------------------------------- |
| 非滚动照片卡组切换 | 1100ms | `styles/presentation-motion.css` |
| 推荐场景入场       | 1450ms | `styles/presentation-motion.css` |
| 列表重排           | 620ms  | `runtime/layout-motion.js`       |
| 阅读图片展开与收回 | 640ms  | `runtime/reader-motion.js`       |

主站的画廊、照片墙、首页信息流和阅读列表共用 `runtime/layout-motion.js`。Next 的图库与资料索引调用同一运行时。相册的吸附位置由外层 `.film-frame` 保持，景深与倾斜作用于内部 `.film-photo`，避免动画改变滚动目标。

相册的可见性通知只控制照片景深，浏览按钮、位置编号和进度不依赖该通知。减弱动效时直接更新相册状态，Home／End 和进度条输入后立即读取滚动位置；完整动效继续合并动画帧内的更新。切换动效和组件卸载会取消等待中的帧与监听。`__tests__/EditorialFilm.spec.ts` 覆盖没有可见性、动画帧和滚动通知时的初始按钮状态、键盘焦点与进度。

`JournalPage` 只为 Next 首页绑定集合筛选的 `change` 事件。主站通过 `sort` 更新路由，避免原生选择框的事件冒泡产生第二次导航并取消排序。首页集成测试要求一次选择只发起一次路由更新，并保留原有卡片节点和完整推荐集合。

`EditorialBrowse` 在布局属性实际变化时捕获旧位置，等待 Vue 更新 DOM 后，由运行时统一读取目标位置，再批量启动 transform 动画。不要恢复成在点击时等待固定帧数猜测路由更新，也不要在每张卡片读取位置后立即写动画。

每个容器只允许最新请求启动动画。新请求从当前可见位置接续并取消旧动画，减少动效直接更新内容。销毁、容器移除或偏好变化后，等待中的请求不能重新播放。无尺寸变化的卡片不需要重排动画。

`reader-motion.js` 捕获点击来源图片的可见位置、裁切位置和比例，在阅读弹窗的顶层临时图层中展开；照片对裁切盒的缩放作反向补偿。关闭过程中保留背景滚动锁，中途关闭从当前几何位置反向收回。完整内容替换初始预览时更新图片引用；结束、减弱动效、隐藏页面或销毁后清除临时图层，并恢复实际阅读图片。浏览器不支持顶层弹出图层时直接展示阅读内容。

实际关闭完成时直接清理滚动锁、阅读返回记录和焦点，原生 `close` 通知可重复到达而不会再次移动焦点。弹窗已经重新打开时，早先关闭的通知不会清除新阅读的临时图层或滚动锁。

减弱动效使用 `transition: none` 取消已经开始的 CSS 过渡，范围包括阅读弹窗和背景层；只把过渡时间改成零不能取消旧的过渡。Next 的品牌字形允许字体合成斜体，避免全局字体规则使字形保持直立。

运行时按元素和动画通道取消旧 WAAPI 动画。指针光照、磁吸和滚动景深由 `viewport-motion.js` 管理；选择指示层由 `selection-motion.js` 管理。恢复自动动效后重新跟随当前系统偏好，减弱动效会取消正在运行的动画并停止推荐播放。

单测入口包括 `runtime/__tests__/layout-motion.spec.js`、`runtime/__tests__/reader-motion.spec.js`、`runtime/__tests__/motion.spec.js`、`__tests__/useCoverPlayback.spec.ts` 和浏览页集成测试。分别验证重排请求、阅读中断与异步加载、自动偏好恢复、播放暂停与卸载，以及真实路由的筛选和重试状态。

本地验证可以运行：

```powershell
& node scripts/run-vitest.mjs run src/features/journal --maxWorkers=1
& node scripts/build.mjs
& node scripts/check-build-security.mjs
& node scripts/check-bundle-budget.mjs
```

构建脚本包含应用类型检查。浏览器验收还需检查 320/390/768/1440 宽度、390×640 短屏、大字号、暗色、键盘焦点、相册吸附、连续推荐切换和阅读中间帧。开发模式可用 `/?journal-fixture=reference` 查看已有示例；跨路由验收时在目标地址保留此参数。示例阅读仅在开发模式启用，生产模式继续使用内容 UUID 与账号权限检查。

示例数据不能证明生产 API、登录后收藏或通知服务可用。动画时间与几何检查也不能证明真实设备的连续播放帧率，不能据此宣称 LCP 或 TBT 改善。

## 主题与滚轮区域

四主题的完整设计与迁移规则见 [外观预设](appearance-presets.md)。主站照片组与 Next 场景增加连续浮动、光照和轨道变化，各主题使用自己的幅度、方向与节奏。继续保留原有卡组切换、场景入场、列表重排和阅读展开动画；静态动效使用独立的 translate/rotate 属性，避免覆盖已有 transform 动画。

增强章节中推荐、相册与预览均使用原生页面滚动；手动控制映射回同一文档进度。未启用增强章节的页面保留区域滚轮：推荐照片、横向相册和 Next 预览只在可见内容的中央接收竖向滚轮。边缘、上下出口、可见面积不足、整页大幅滚动、修饰键、表单及原生横向手势保留浏览器行为。滚到第一项或最后一项后继续向外滚动会回到页面；推荐不会通过滚轮首尾循环。相册在区域滚动期间临时关闭吸附，停止后恢复。

Next 列表上的普通页面滚动会选择靠近指针的可见记录，并更新预览，不移动键盘焦点。指针移动、键盘输入或滚轮进入预览后结束这次列表跟随。非增强模式下预览中央可逐项浏览，两端释放页面滚动。区域逻辑集中在 editions/wheelRegion.ts；列表跟随位于 editions/useCollectionScroll.ts。异步推荐内容出现后重新绑定区域监听，卸载时清理。

回归测试覆盖区域中央与边缘、首尾释放、修饰键、表单、横向手势、异步内容绑定、卸载，以及列表滚动不抢键盘焦点。
