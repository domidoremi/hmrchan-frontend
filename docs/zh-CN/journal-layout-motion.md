# 浏览视图重排动效

主站的画廊、照片墙和阅读列表共用 `runtime/layout-motion.js`。Next 使用独立的资料列表，运行时代码保持同步。

`EditorialBrowse` 在布局属性实际变化时捕获旧位置，等待 Vue 更新 DOM 后，由运行时统一读取目标位置，再批量启动 transform 动画。不要恢复成在点击时等待固定帧数猜测路由更新，也不要在每张卡片读取位置后立即写动画。

每个容器只允许最新请求启动动画。新请求从当前可见位置接续并取消旧动画，减少动效直接更新内容。销毁、容器移除或偏好变化后，等待中的请求不能重新播放。无尺寸变化的卡片不需要重排动画。

验证入口：`runtime/__tests__/layout-motion.spec.js` 与 `__tests__/EditorialBrowse.spec.ts`。几何排序与生命周期由单测覆盖；真实中间帧、主题尺寸、焦点和性能需浏览器验收。此优化不在首页启动路径，不能据此宣称首页 LCP 或 TBT 改善。

## 首页区域输入与环境动效

`editions/ScrollRegion.vue` 共用于封面、影像和 Next 首页索引。完整动效下，只有 `data-scroll-content` 内的纵向滚轮参与本组浏览：封面和索引依次选中记录，影像轨道按滚轮距离横向移动。标题、正文和外侧留白直接滚动页面；本组到达首尾后也将输入交还页面。各组使用现有布局高度。

小幅触控板输入会累积，连续换卡有短暂间隔，反向操作可立即回看。缩放、横向触控板、输入控件和打开的弹窗保持原有输入行为，自动选中不移动键盘焦点。手机竖滑继续翻页，明确的横滑切换封面或预览，影像栏保留原有横向触摸滚动。减弱动效或封面暂停时，纵向滚轮直接翻页。

`styles/home-motion.css` 使用 `translate` 和透明度添加静止时的缓慢升降与光线变化，并与既有入场、倾斜和换卡动画叠加。区域离开视口、键盘聚焦、标签页隐藏和封面暂停时停止环境动效。动效偏好位于显示设置中，普通首页尊重系统及本设备保存的选择。

`__tests__/ScrollRegion.spec.ts` 覆盖区域区分、首尾释放、输入累积、反向浏览、暂停、减弱、弹窗、影像平移和手机手势。浏览器验收还需确认真实动画中间帧、焦点、路由往返，以及 Next 手机浮动选中栏在预览离开视口后才显示。
