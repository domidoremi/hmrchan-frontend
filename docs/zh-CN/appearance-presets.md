# 外观预设

[返回中文 README](../../README.md) · [English](../en/appearance-presets.md)

两站共用四个主题和同一套语义变量，保留各自的页面结构。主站侧重阅读、章节和照片卡组；Next 侧重检索、索引预览和立体场景。主题切换同时改变布局比例、排版、边框、控件、交互状态和动效，不改变路由与数据。

首次访问时主站默认纸页，Next 默认光谱；已有有效主题选择保持不变。完整动效默认开启，恢复显示默认也恢复完整动效；用户明确保存的跟随系统或减弱选择继续生效。

| 主题 | 稳定 ID            | 布局与元素                                                      | 动效                       |
| ---- | ------------------ | --------------------------------------------------------------- | -------------------------- |
| 纸页 | minimal-editorial  | 暖纸色、衬线阅读、分隔线和矩形照片；Next 保留索引字形与圆润控件 | 小幅垂直浮动、平缓切换     |
| 玻璃 | fluent-soft        | 蓝色层次、圆角内嵌面板、独立记录行；推荐与预览采用均衡分栏      | 较明显的垂直浮动、柔和缓动 |
| 自然 | organic-natural    | 绿与亚麻色、不对称矩形边框、更宽的阅读留白与行距                | 缓慢斜向移动与轻微旋转     |
| 光谱 | gradient-narrative | 紫色光感、分割构图、宽幅首篇与强调边线；Next 使用不同的面板轮廓 | 横向漂移、光照和轨道呼吸   |

每个主题提供独立明暗色板。强调色上的文字使用专用前景变量，避免深色模式下亮按钮配白字。首页、浏览、日程、讨论、搜索、作者、阅读弹窗、登录、账号与设置表面共享颜色、焦点、边框和尺寸约定。图片区上的文字使用独立遮罩。

## 实现边界

- ID 和旧值迁移位于 `src/config/appearance.ts`；四个轻量色板随全局样式加载，切换不再发起 CSS 请求。
- `src/styles/presets/system.css` 定义全局与旧组件共享的变量；四个同目录色板定义主题差异。
- Journal 的 `styles/themes.css` 与 `styles/theme-pages.css` 定义场景布局、组件状态与延迟加载页面的主题规则。
- 首页的 `styles/home-composition.css` 定义连续章节构图，`styles/home-themes.css` 定义四主题的比例、轮廓和运动参数。`HomeAtmosphere` 共享背景，标题、照片、光照和目录由文档滚动进度联动。
- 完整、减弱及跟随系统三种动效选项位于显示设置。减弱动效取消连续运动；隐藏页面与离屏推荐暂停相关动画。
- 移动布局保留内容顺序、触控尺寸、键盘焦点与大字号阅读，不使用拱形封面。
