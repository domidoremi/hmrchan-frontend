# Edition 02.5 渲染边界复核

本次迁移保留原型的静态构图与 SVG 路径。`JournalShell` 仅渲染仓库内两个 chrome JSON；`JournalScene` 仅调用仓库内五类固定场景；`JournalIcon` 仅从固定图标字典取路径。三处 `v-html` 均不接收接口 HTML、查询字符串或用户输入，因此按文件纳入前端审计白名单。

真实帖子、讨论、日程和收藏在 Vue 模板中以文本绑定呈现。原型详情弹窗的动态标题、内容、标签、作者和属性值全部经 `UI.escape` 转义；活动外链仅允许 HTTP/HTTPS；帖子链接由已校验的 UUID 构造。固定场景中的照片路径和文案来自仓库。`reference-data.json` 和 `/__journal` 只在 DEV 分支启用，不作为正式业务数据。

会话继续由现有身份服务、路由守卫和安全弹窗处理。收藏与发帖操作等待真实会话恢复，账户变化清除临时收藏状态；数据请求取消与序号校验防止旧响应覆盖新页面。可见性观察使用共享 `createVisibilityObserver`，运行时统一清理监听、观察器和动画帧。

复核范围包括三处静态 HTML 入口以及 `JournalPage` 的真实内容详情和图片弹窗。后续若增加远程 HTML 或允许可编辑富文本，必须重新审核该边界并使用项目现有的净化流程。
