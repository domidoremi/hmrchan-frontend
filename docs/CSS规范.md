#### 核心原则

- **禁止强制写死 px**（max-width、min-width 以及微观细节除外）。
- **优先使用单位顺序**：
  1. 百分比 (%)
  2. Flexbox (flex: 1 等) 与 Grid (1fr)
  3. 视口单位 (vw、vh、dvh、svh、lvh 等)
  4. rem（根 em）
  5. ch（字符宽度，适用于文本容器）
  6. 流体函数（clamp()、min()、max()）作为辅助，实现平滑缩放

#### 布局与尺寸逻辑（分层原则）

1. **宏观布局（大色块、分栏）**
   - 首选 Flexbox 或 Grid。
   - Grid 中**优先使用 1fr**（而非 %），以确保剩余空间分配更精确、不受内容尺寸干扰。
   - 结合百分比 (%) 或 fr 单位实现流体分配。

2. **容器限制（防止内容过宽）**
   - 优先使用**更灵活的表达式**，而非固定 px：
     - `max-width: min(90vw, 1440px)`（推荐默认）
     - 或 `max-width: 80ch` / `65ch`（适用于文本为主的内容，提升可读性）
     - 如需固定上限，可保留 `max-width: 1440px` 等 px 值（向下兼容）。

3. **视口相关高度（尤其是移动端）**
   - 手机端**必须使用 dvh / svh / lvh** 代替传统 vh，避免地址栏、工具栏导致的布局跳动。
   - 示例：`min-height: 100dvh` 用于全屏容器。

4. **间距、文字与排版**
   - **文字大小与间距统一使用 rem**。
   - 进一步推荐结合**流体函数**实现平滑缩放：
     - 字体：`font-size: clamp(1rem, 2.5vw + 0.5rem, 1.5rem)`
     - 间距：`padding: clamp(1rem, 5vw, 3rem)`
     - 这能在小屏与大屏间提供更自然的过渡。

5. **微观细节（图标、边框、阴影等）**
   - 允许使用 px，确保在高 DPI 屏幕下的像素级精确控制。
   - **独立图标**（如侧边栏、工具栏按钮、独立装饰性图标）：**使用 px**，防止在字体缩放或容器压缩时变形。
   - **文本内的行内图标（Inline Icons）**：**建议使用 em**，使其随当前文本字体大小同步缩放，保持视觉一致性与可访问性。

6. **文本宽度优化**
   - 正文容器强烈建议使用 **ch 单位**限制宽度（如 `max-width: 65ch ~ 75ch`），符合排版学最佳实践（每行字符数控制在 50–75）。

#### 实现

- 极高的响应式与自适应能力（Flex/Grid + fr + 流体函数 + 动态视口）
- 出色的可访问性与可读性（rem + em + ch + clamp）
- 精细的细节控制（图标单位区分 + 必要 px 保留）
- 与主流框架（Tailwind CSS、Bootstrap 5.3+、Material 3、Ant Design）高度兼容
